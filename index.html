how it works

  
you get a random thing to build. an app, a website, a game, whatever. there's no answer, you just have to make it. if it's too big, make a tiny piece of it first.

  
python, javascript and php run in your browser. python and php take a few seconds to load the first time. html and css show up in a box under the editor.

  
c, c++, c#, rust, go, java, kotlin, swift, ruby and lua get sent to godbolt.org to compile and run, so don't paste anything private. if your program asks for input, type it in the input box before you hit run.

  
holy c only runs in templeos, so you can write it here but not run it. sorry.

  
nothing gets saved. refresh and it's gone.

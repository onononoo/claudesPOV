how it works

  
every prompt is a small project: an app, a website, a tool or a game. there is no answer attached. write it in the box, press run, read what comes back, fix it, run it again. if a prompt feels too big, build the smallest piece of it first. if you don't like it, take another.

  
python, javascript and php run right here in this browser. the first python or php run takes a few seconds while the language loads. html is drawn in a frame under the editor, and css styles a small sample page so there is something to look at.

  
c, c++, c#, rust, go, java, kotlin, swift, ruby and lua are sent to compiler explorer (godbolt.org) to be compiled and run, and the output comes back here. don't put anything private in that code. programs there get a few seconds and no internet, and anything they read from the keyboard has to be typed into the input box before you press run.

  
holy c can be written here but not run. it only lives inside templeos.

  
nothing is saved. each language keeps its code while the page is open, and a refresh clears everything.
